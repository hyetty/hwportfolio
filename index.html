가상 종합병원을 직접 구축해 표적형 침해사고를 재현하고, 디스크·메모리·로그 아티팩트로 공격의 전 과정을 시간 순으로 복원했습니다.

개요

국내외 병원을 노린 랜섬웨어가 늘어나는 흐름에 맞춰, 의료기관 환경을 기반으로 침해사고를 재현하고 포렌식 분석까지 전 과정을 수행한 프로젝트입니다. 공격자는 다크웹에서 병원 정보를 사들인 뒤 스피어피싱과 웹서버 취약점으로 내부에 들어와 AD를 장악했고, 환자정보와 의료영상을 빼낸 다음 랜섬웨어를 배포했습니다.

팀은 이 시나리오를 직접 구현한 뒤, 분석관 역할을 나눠 시스템별로 증거를 수집·분석했습니다.

  • 95쪽 분량의 침해사고 분석 보고서를 작성했습니다 (최종 보고서).
  • 최종 평가에서 5개 팀 중 2위를 기록했습니다.
  • 154장 발표자료를 제작해 최종 발표를 맡았고, 현업 멘토의 기술 검토를 받았습니다.

침해사고 시나리오

AIF 종합병원(공개 도메인 aif.org, 내부 AD 도메인 hospital.local)을 표적으로 한 공격 흐름입니다. 붉게 표시한 구간이 제가 분석한 메일서버입니다.

  1. 09-06다크웹에서 AIF 병원 구성도·메일서버 접근 정보 구매
  2. 09-07행정 PC 1차 스피어피싱(무료 접종 안내 위장, update.exe). 장악은 성공했지만 AD 횡이동은 내부 방화벽에 막힘
  3. 09-11DMZ 웹서버 파일 업로드 취약점으로 웹쉘 업로드, PrintSpoofer로 SYSTEM 권한 상승, mimikatz로 자격증명 탈취
  4. 09-14웹서버를 거쳐 메일서버에 SSH 침투, 관리자 메일 양식을 훔쳐 정보보안팀을 사칭한 2차 스피어피싱 발송 MY PART
  5. 09-14~관리자 PC 장악(UAC 우회, 백도어 계정 ops), 저장된 계정 파일과 CrackMapExec로 AD 도메인 관리자 탈취
  6. 이후AD를 거점으로 의사 PC·협력업체 PC로 이동해 포털/DB 환자정보와 PACS 의료영상 약 130GB를 SoftEther VPN으로 반출
  7. 10-01백업서버 파괴, GPO를 이용해 서버망·행정망·PACS에 랜섬웨어 배포

구축 환경

행정망·서버망·DMZ·의료장비망 등 141대 규모로 병원망을 설계하고, 그중 시나리오에 필요한 17대(서버 7, PC 4, 의료장비 3, 공격자 2, 가상 방화벽 1)를 VirtualBox에 실제로 구축했습니다. 구간 사이는 pfSense로 라우팅·필터링했습니다.

분석 절차와 도구

수집, 보존, 분석, 검증, 보고의 5단계 표준 절차를 따랐습니다. 휘발성이 높은 메모리부터 수집하고, VM을 끈 상태에서 원본 가상디스크를 raw(dd)로 복제한 뒤 SHA-256 해시를 남겼습니다. 분석은 읽기 전용 사본으로만 진행했습니다.

2. 의료장비망 X-ray 모달리티 구축

의료장비망(NET40)에 X-ray 모달리티 VM(Ubuntu, 192.168.40.11)을 만들고, Orthanc PACS(192.168.40.60)로 DICOM 영상이 전송되도록 연동했습니다. 시나리오 후반의 PACS 의료영상 유출이 실제 영상 데이터 위에서 일어나도록 만든 기반 작업입니다.

3. 증거물 무결성 기준값 산출

행정 PC, 웹서버, 메일서버 증거물의 수집 시점 SHA-256 해시를 certutil -hashfile과 sha256sum으로 산출해 기록했습니다(현장 기록 P-06). 이 값은 분석 시점에 FTK Imager로 다시 계산한 해시와 대조해 원본성을 입증하는 데 쓰였습니다.

4. 최종 발표자료 제작 · 발표

154장 분량의 최종 발표자료를 제작하고 발표를 맡았습니다. 포렌식이 남겨진 단서를 따라 사건의 전말을 밝힌다는 점이 영화의 서사와 닮았다는 데서 착안해 '영화 프레임'을 시각 콘셉트로 잡았습니다. 표지는 클래퍼보드, 슬라이드 테두리는 필름으로 꾸미고, 수사팀 롤플레잉과 담당자 인터뷰 장면을 넣어 사건 발생부터 흔적 발견, 분석, 추적까지를 하나의 이야기로 이어지게 구성했습니다.

  • 10명이 나눠 분석한 시스템별 결과를 공통 양식(분석 대상 표시 바, 핵심 문장 콜아웃, 증거 캡처)으로 통일
  • 시스템 구조도와 공격 경로를 단계별 애니메이션으로 보여 주어 흐름을 따라가기 쉽게 구성

분석 결과와 대응

IoC 기반 스크립트로 피해 범위를 산정한 결과 141대 중 111대(79%)가 피해를 입었고, 환자 개인정보·진료기록과 의료영상 약 130GB가 유출됐습니다.

메일서버 구간에 대해서는 다음 대응을 제안했습니다.

  • SSH root 로그인 차단, 키 기반 인증 전환, 로그인 실패 시 계정 잠금
  • 메일 게이트웨이에서 실행파일(.exe) 첨부 차단
  • Postfix 3.4.13 → 3.9.0 업그레이드와 위장 발신 도메인 필터·스팸 차단 적용
  • IoC 등록: 위장 도메인 yourorg.ai, 사칭 주소 wellness@yourorg.ai · security@aif.org, 페이로드 sec_update.exe

개요

홈캠 사용이 늘면서 해킹으로 사생활 영상이 유출되는 사고도 함께 늘고 있습니다. 하지만 기존 보안 기술은 대부분 네트워크 전송 구간에 집중되어 있어, 영상 원본이 탈취되면 프라이버시를 지킬 방법이 사실상 없습니다.

이 프로젝트는 영상을 서버에 저장하기 전에 등록된 사용자의 얼굴과 노출된 신체를 마스킹해, 원본이 새어 나가도 사생활이 드러나지 않도록 합니다. 2025 이화여자대학교 캡스톤디자인 경진대회에서 은상을 받았습니다.

얼굴 마스킹

사용자가 정면·측면 등 여러 각도로 얼굴을 등록하면 각 이미지의 임베딩 벡터를 평균해 사용자 고유 임베딩으로 저장합니다. 영상 속 얼굴과의 코사인 유사도가 0.7 이상이면 같은 인물로 보고, 네모·블러·이모지 중 사용자가 고른 방식으로 가립니다.

신체 마스킹 MY PART
